## 31 августа 2026 — Проектирование и блок 1

### Проектирование

Проведён разбор постановки в четыре раунда вопросов. Закрыты все ветки решений:
стек, хранилище, хостинг, ИИ, регистрация, права, календарные правила, эскалация,
администрирование, порядок работ. Результат — 16 решений в `DECISIONS.md`.

Ключевые развилки, которые были сняты:

- Firebase отклонён в пользу PostgreSQL с шестью обоснованиями.
- Бесплатный хостинг (Oracle Always Free) отклонён: в 2026 году лимит урезан вдвое,
  простаивающие машины отзываются через 7 дней.
- Бесплатный тариф Gemini отклонён: контент используется для обучения и его видят
  живые ревьюеры. Выбран платный OpenAI API — на нём данные не используются.
- Самостоятельный выбор роли ограничен: повышенные роли выдаёт только человек.

Выпущен документ архитектуры `Архитектура SETA.html` — 19 разделов: схема системы,
модель данных на 38 таблиц, матрица прав, ИИ-контур, 15 показателей аналитики,
20 функций, план на 14 недель, риски.

### Разработка

Реализован **блок 1 — ядро**:

- каркас проекта: Docker Compose, Dockerfile, Alembic, dev-оверрайд с монтированием
  исходников, `.env.example`, `/health`;
- 16 таблиц, первая миграция `992adea33371_block1_core`;
- каталог из 28 прав и матрица ролей на 69 связок;
- регистрация тремя путями с подтверждением телефона;
- middleware авторизации: одна транзакция на апдейт, права в контексте обработчика;
- индикатор доступности руководителя с автоистечением и поздним приёмом;
- администрирование в боте: заявки, сотрудники, отделы, ссылки, журнал;
- журнал аудита с полями «было/стало» и настоящим автором при делегировании.

### Проверено

`scripts/smoke_block1.py` — 26 сценариев, 0 ошибок. Проверены в том числе отказы:
чужое поручение, соседний отдел, пересланная ссылка с повышенной ролью,
отсутствие прав до подтверждения заявки.

Схема применена к живой базе, наполнение справочников идемпотентно
(повторный запуск не создаёт дублей).

### Решённые проблемы окружения

- Docker Desktop не был запущен — запущен.
- Порты 5432, 6379 и 8000 заняты другими проектами владельца (`mailing`, `ai_tmk`).
  SETA переведена на 55432, 56379, 8010.
- Слой `apt-get` в образе падал и был не нужен — удалён.
- Миграция, сгенерированная в контейнере без монтирования, терялась —
  добавлен `docker-compose.dev.yml`.

### Осталось

Бот ни разу не запускался с настоящим токеном: владелец должен вписать `BOT_TOKEN`
и `BOOTSTRAP_ADMIN_TELEGRAM_ID` в `seta/.env`. Сервер не арендован, домена нет.
