# Mini App

Приложение Telegram поверх того же API, что отвечает боту. Блок 5, фаза 8.

## Что оно делает и чего не делает

**Читает.** Мой день, поручения с разрезами и карточкой, встречи на две недели,
реестр решений. Состав вкладок собирается по ролям и включённым разделам —
тем же списком, по которому бот собирает нижнее меню.

**Не меняет.** Маршрутов записи в API нет ни одного. Принять поручение, сдать
работу, подтвердить встречу — в чате. Кнопка, за которой ничего нет, обманывает
дважды: сначала обещает, потом отказывает.

**Ничего не считает.** Все числа и все подписи приходят с сервера уже
посчитанными и уже переведёнными. Сложи приложение два числа само — в чате
и в приложении разошлись бы цифры, и обе стороны выглядели бы правдиво.

**Своего словаря у него нет.** Названия вкладок, разрезов и пустых состояний
приходят в `/me` из того же `app/i18n`, что у бота. Второй словарь разошёлся бы
с первым молча, и переводить пришлось бы дважды — а вычитывает узбекский
владелец, и один раз.

## Сборка

```bash
cd seta/miniapp
npm install
npm run build          # tsc --noEmit && vite build → dist/
npm run dev            # локально, на http://localhost:5173
```

Адрес API подставляется при сборке:

```
VITE_API_URL=https://seta.example.uz
```

Пусто — приложение говорит об этом прямо, а не делает вид, что данных нет.

## Развёртывание на Vercel

Репозиторий подключается к Vercel, в настройках проекта:

| Поле | Значение |
|---|---|
| Root Directory | `seta/miniapp` |
| Framework Preset | Vite |
| Build Command | `npm run build` (по умолчанию) |
| Output Directory | `dist` (по умолчанию) |
| Environment Variable | `VITE_API_URL` — адрес API |

Дальше каждый push в ветку собирается сам. `vercel.json` рядом задаёт то же
самое на случай, если настройки проекта пустые.

## Две настройки, без которых оно не заработает

**Со стороны бота** — `MINIAPP_URL` в `.env`: адрес приложения со схемой.
Он делает две вещи сразу: включает кнопку «Меню» в чате и разрешает браузеру
обращаться к API. Пусто — приложения нет: кнопки не будет, и запросы
не пройдут.

**Предварительные сборки не работают с боевым API, и это правильно.** Vercel
выдаёт каждому коммиту свой адрес, а разрешён только тот, что записан
в `MINIAPP_URL`. Черновик не приложение, и проверять правки на живых данных
кабинета — не то, чего хочется случайно.

## Чего здесь нет

**Администрирования.** Заявки, сотрудники, отделы, ссылки, праздники, лимиты —
в боте. В API этих маршрутов нет вовсе, а рисовать экран поверх несуществующего
API нельзя.

**Сетки календаря по часам.** Встречи показаны списком с разделителями по дням.
Сетка на телефоне шириной в 360 точек читается хуже списка, и делать её надо
тогда, когда появится планшет или веб — а не потому, что она была в плане.
